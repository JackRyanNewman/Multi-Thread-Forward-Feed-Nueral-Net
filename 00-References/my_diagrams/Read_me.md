My Neural_Net is just a standard neural network diagram, but annotated with the actual variable names my program uses.

My_data_Structure was created specifically for me as an abstract way to visualize how my data flows, it isn’t meant to represent a standard modeling system. Even though it may look like components are connected in a traditional way, the entire architecture of my neural network is built around optimization. The only true array of objects is the array of layer objects. Each layer object simply holds references to parallel double arrays: PrevJ, Weights (Neurons), and Inj. By relying on straightforward relationships between these parallel arrays, I can avoid unnecessary complexity and achieve significant speed improvements.s
